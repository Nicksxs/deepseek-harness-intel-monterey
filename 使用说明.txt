DeepSeek Harness Intel Mac / macOS Monterey 源码适配包

目标：Intel MacBook Pro，macOS 12.6.6 (21G646)。
这是小体积下载启动包，不是可以直接安装的 DMG。它从官方 GitHub 下载固定版本源码，校验 SHA256，应用附带补丁，再编译启动。尚未完成 macOS 实机启动验收。

修改内容
1. 桌面 Electron 固定为 43.7.7。Electron 44 已停止支持 macOS 12。
2. 仅 mac-x64 的独立 Node 运行环境固定为 22.23.3，使用官方 SHA256 校验；其他平台保留原版本。
3. 修复生成的 Harness Dev.app 从 Finder 冷启动时丢失主运行环境目录的问题。
4. 添加中文启动脚本，先检查平台和工具，再安装项目依赖并编译启动。
这是面向 Monterey 的源码变体，Electron 版本固定对本源码副本的所有桌面构建生效。

准备（需要你在 Mac 上完成；启动脚本不会自动安装系统工具）
- x64 Node.js 22.23.3 完整发行版，需包含 include/node/node_api.h：
  https://nodejs.org/dist/v22.23.3/
  选择 node-v22.23.3-darwin-x64.tar.gz，或官方对应 macOS 安装包；不要用 Node 24。
- pnpm 11.7.0。安装 Node 后可自行运行 npm install -g pnpm@11.7.0
- Xcode Command Line Tools：终端执行 xcode-select --install，然后完成系统安装提示。
- 可用网络和足够磁盘空间；首次下载依赖和编译可能较久。

使用
1. 完整解压本 ZIP，把解压后的文件夹放在准备长期保留的位置。
2. 在“终端”执行 cd 后拖入这个文件夹，再回车。
3. 执行 bash ./Setup-Intel-Monterey.command
   也可双击 Setup-Intel-Monterey.command；若 Finder 的 PATH 找不到已安装工具，请改用终端方式。
4. 启动器下载约32MB官方源码、校验后应用补丁，生成 deepseek-harness-intel 子目录，再下载依赖并编译打开客户端。
5. 后续启动执行 bash ./deepseek-harness-intel/Start-Intel-Monterey.command；已成功构建后，也可打开该源码目录下 apps/desktop/.desktop-build/development/Harness Dev.app。
6. 若编译失败，请保留终端完整错误输出。已有源码目录不会被覆盖。后续无需再次运行 Setup。
7. .app 依赖源码目录、node_modules 和生成的运行环境；请勿单独复制.app，或移动/删除源码目录。
8. 首次使用在界面中配置账号或 API Key，请勿把密钥写进本包。

已有源码报 dsh-app-boot/lib/index.js 缺失时
这属于构建顺序问题：旧开发启动器提前导入了尚未构建的模块。无需重新下载源码。使用新适配包里的修复工具：
node ./repair-existing-source.mjs "已有的 deepseek-harness-intel 目录"
修复会备份原启动脚本，只调整已知启动命令；然后在原源码目录运行 bash ./Start-Intel-Monterey.command。
新的启动顺序为先 pnpm run build，再 pnpm run start:desktop；前一步失败不会启动客户端。
